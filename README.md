# Michigan Football RTP Dashboard — Public Demo

Interactive staff-review prototype of the return-to-play dashboard using **fictional data only**.

## View the dashboard

Once GitHub Pages is enabled for the `main` branch and repository root, the website will be available at:

https://hjpat.github.io/michigan-football-rtp-demo/

Until then, you can open the `index.html` file locally.

## Features

- Team Overview with RTP roster and milestone summaries
- Athlete Profile with healthy baselines, recovery trends, bilateral comparisons, and prior injury history
- Speed Profile with personalized velocity-band exposure, recovery benchmarks, and max-velocity progression

**Not a clearance tool.** Data are illustrative. Recovery benchmarks are intended to support professional interpretation, not determine medical readiness.

## Development and privacy

This public repository is only for the fictional, shareable frontend. Development of future Catapult/VALD integrations should remain in the **private** development repository and on university-approved infrastructure. Never commit real athlete injury/performance information, tokens, credentials, or confidential vendor exports here.

## Enable GitHub Pages

Repository **Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save**.
